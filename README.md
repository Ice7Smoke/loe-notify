# ⚡ Сповіщення про графік відключень Львівобленерго в Telegram

Кожні 10 хвилин програма перевіряє графік погодинних відключень (ГПВ) на poweron.loe.lviv.ua.
Якщо графік на сьогодні чи завтра **для твоєї групи** з'явився або змінився, вона надсилає тобі в Telegram повідомлення з годинами та картинкою графіка.

Програма працює безкоштовно на GitHub Actions, тому комп'ютер тримати увімкненим не треба.

---

## 1. Створи Telegram-бота (2 хв)

1. У Telegram відкрий **@BotFather** і надішли `/newbot`.
2. Придумай назву та юзернейм (наприклад `my_lviv_svitlo_bot`).
3. Скопіюй **токен**, він має вигляд `123456789:AAH...`. Нікому його не показуй.
4. Знайди свого нового бота й натисни **Start**. Без цього бот не зможе тобі писати.

## 2. Дізнайся свій chat id

Напиши боту **@userinfobot**, і він відповість твоїм `Id`, наприклад `412345678`.

## 3. Дізнайся свою групу

На poweron.loe.lviv.ua відкрий «Чому немає світла?» → «Дізнатися чергу», введи адресу. Отримаєш номер на кшталт `1.1`, `3.2` тощо.

## 4. Залий програму на GitHub

1. Зареєструйся на github.com і створи новий репозиторій (**New repository**). Обери **Public**: для публічних репозиторіїв GitHub Actions безкоштовний без ліміту. Токен і chat id ніхто не побачить, бо вони зберігаються в Secrets.
2. Натисни **uploading an existing file** і перетягни файли:
   - `loe_notify.py`
   - `.github/workflows/loe.yml`. Це файл має лежати саме в папці `.github/workflows/`. Найпростіше натиснути **Add file → Create new file**, ввести назву `.github/workflows/loe.yml` і вставити вміст.
3. Відкрий **Settings → Secrets and variables → Actions**:
   - вкладка **Secrets** → **New repository secret**:
     - `TELEGRAM_BOT_TOKEN` = токен із кроку 1
     - `TELEGRAM_CHAT_ID` = id із кроку 2
   - вкладка **Variables** → **New repository variable**:
     - `LOE_GROUP` = твоя група, наприклад `1.1`. Якщо цю змінну не задати, приходитимуть усі групи.

## 5. Перевір

**Actions** → **LOE outage notifier** → **Run workflow**.
Під час першого запуску прийде поточний графік, далі повідомлення надходитимуть лише при змінах.

---

## Альтернатива: запуск на своєму комп'ютері

```bash
export TELEGRAM_BOT_TOKEN="123456789:AAH..."
export TELEGRAM_CHAT_ID="412345678"
export LOE_GROUP="1.1"
python3 loe_notify.py --test   # надіслати поточний графік зараз
python3 loe_notify.py --loop   # перевіряти кожні 10 хв, поки вікно відкрите
```

(У Windows використовуй `set` замість `export`.)

## Важливо знати

- Дані надходять із неофіційного API (`api.loe.lviv.ua`), яким користується сам сайт ЛОЕ. Якщо Львівобленерго його змінить, програма може перестати працювати. У такому разі зазирни у вкладку **Actions**, там буде видно помилку.
- GitHub може запускати перевірки із затримкою 5–15 хв у години пік.
- Якщо в репозиторії 60 днів не буде жодної активності, GitHub призупинить розклад. Щоб його відновити, достатньо натиснути **Enable workflow** у вкладці Actions.
- Офіційні способи отримати графік: чат-бот Львівобленерго у Viber/Telegram, Telegram-канал @lvivoblenergo і e-mail розсилка в особистому кабінеті на info.loe.lviv.ua.
